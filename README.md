# LaTeX_tutorial

本仓库包含 [LaTeX入门教程] 系列文章中所用的全部 LaTeX 示例代码。每一份代码都是独立完整的 `.tex` 文件，可以直接编译生成 PDF，帮助你边学边练。

如果发现任何问题或有任何建议，欢迎反馈。我们也将持续更新。

## 内容
| 文件/目录 | 对应教程板块 | 说明 |
|-----------|--------------|------|
| `example1.tex` | 概念与编译 | 基本结构 |
| `example2.tex` | 概念与编译 | 支持中文 |
| `example3.tex` | 排版篇 | 页面与段落 |
| `example4.tex` | 排版篇 | toc和引用演示 |
| `简易模版.tex` | 全部板块 | 提供了一个模板，并演示了一些排版形式和公式 |
| `pic` | 素材 | 图片插入演示 |

## 环境要求与编译方法

### 推荐工具
- **在线编辑器**：[Overleaf](https://www.overleaf.com) / [sjtuLaTeX](https://latex.sjtu.edu.cn/) 
- **本地环境**：TeX Live 2022 以上 / MiKTeX（Windows） / MacTeX（macOS）等

注：含参考文献的文档可能需要多次编译。

## 更多阅读

texdoc symbol: 数学符号表，是mathfont宏包附带的数学符号表大全。
LaTeX公式编辑器: [在线LaTeX公式编辑器-编辑器](https://link.zhihu.com/?target=https%3A//www.latexlive.com)，这个网站不仅提供了编辑器，可以通过公式反推出LaTeX公式与环境代码，还包括一个比较详细的帮助文档。
